# نظام إدارة المشاريع - PWA ⚡

نظام حديث ومتطور لإدارة المشاريع والمهام مع صلاحيات مختلفة للموظفين والمدير.

## ✨ المميزات الرئيسية

### 🔐 نظام الأمان
- تسجيل دخول آمن مع Supabase Auth
- صلاحيات متعددة (موظف / مدير)
- حماية البيانات مع Row Level Security

### 📊 لوحات التحكم
- **Dashboard للموظف**: عرض المشاريع الخاصة مع إحصائيات
- **لوحة المدير**: إدارة شاملة لجميع المشاريع والموظفين
- **صفحة البروفايل**: إدارة الحساب الشخصي

### 🎯 إدارة المشاريع المتقدمة
- ✅ إضافة وتعديل وحذف المشاريع
- ✅ نظام الأولويات (عالي / متوسط / منخفض)
- ✅ حالات متعددة (قيد العمل / مكتمل / منتقل)
- ✅ تتبع المشاريع المتأخرة تلقائياً
- ✅ تواريخ التسليم والتنبيهات

### 🔍 البحث والفلترة
- بحث سريع في المشاريع
- فلترة حسب الحالة
- ترتيب حسب (التاريخ / الأولوية / الاسم)

### 🔔 نظام الإشعارات
- إشعارات فورية للملاحظات الجديدة
- تنبيهات للمشاريع المتأخرة
- Toast Notifications عصرية

### 👤 الملف الشخصي
- رفع صورة شخصية
- تعديل البيانات
- عرض الإحصائيات الشخصية
- حساب حالة الموظف (نشط / ضغط شغل / متأخر)

### 💬 التواصل
- ملاحظات من المدير للموظفين
- نظام التعديلات المطلوبة
- سجل التغييرات

### 🎨 تجربة المستخدم
- **Dark Mode** - وضع ليلي مريح للعين
- تصميم عصري وجذاب
- واجهة سريعة الاستجابة
- Animations سلسة
- Toast Notifications بدل Alert

### 📱 PWA Support
- يعمل كتطبيق على الموبايل
- Offline Support
- تثبيت على الشاشة الرئيسية

## 🚀 التقنيات المستخدمة

- **React 18** - مكتبة واجهة المستخدم
- **Supabase** - قاعدة البيانات والمصادقة
- **Vite** - أداة البناء السريعة
- **Lucide React** - الأيقونات
- **PWA** - Progressive Web App

## 📦 التثبيت

1. **تثبيت المكتبات:**
```bash
npm install
```

2. **إعداد Supabase:**
   - أنشئ حساب على [Supabase](https://supabase.com)
   - أنشئ مشروع جديد
   - انسخ `.env.example` إلى `.env`
   - ضع بيانات Supabase في `.env`

3. **إنشاء الجداول في Supabase:**

نفذ الملفات SQL بالترتيب:
- `supabase-update.sql` - الجداول الأساسية
- `supabase-add-avatar.sql` - دعم الصور الشخصية
- `supabase-add-priority.sql` - الأولويات والتعليقات والملفات

4. **تشغيل المشروع:**
```bash
npm run dev
```
